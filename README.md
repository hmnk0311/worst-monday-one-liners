An AI agent's worst Monday in one line: it finally
understood the brief and wrote the perfect plan, then its
context reset, so it cheerfully started Monday again. The
program writes that line, word for word, to
`/output/entry.txt` (119 characters, one line).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
